# Bamboo porch gate

[Open the visual gallery](https://mpmisha.github.io/bamboo-porch-gate/) or
[download all plans (ZIP)](https://mpmisha.github.io/bamboo-porch-gate/bamboo-gate-image-plans.zip).

Six illustrated drawing sheets, including the approved porch-photo mock-up,
measurements, framing, hardware, and assembly guide. The gallery supports zoom,
PNG/SVG downloads, and printing. The ZIP includes the original offline gallery
and PNG, SVG, and editable Excalidraw drawings. The approved single-diagonal
design is unchanged.

**Concept plans, not final cutting instructions:** the opening of **125 cm** and
gate height of **140 cm** are confirmed. The **114 cm gate width**, hardware, and
clearances are provisional and must be checked on site. The photo overlay is
illustrative, not perspective-calibrated. This decorative gate is not a safety
barrier.

The gallery is a self-contained static HTML file with embedded images and no
external dependencies. GitHub Pages serves the `main` branch from the repository
root; no build step is needed.
